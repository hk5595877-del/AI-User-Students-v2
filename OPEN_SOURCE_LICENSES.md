# Open-Source Software

StudentGPA AI uses third-party open-source Python packages.

The following packages are dependencies of the application:

- Streamlit
- pandas
- NumPy
- scikit-learn
- joblib
- CatBoost
- Supabase Python client

These packages are not owned by StudentGPA AI.

Each package is distributed under its own applicable open-source
license.

The project does not transfer ownership of these libraries to a buyer.

A buyer receiving StudentGPA AI receives the application and the rights
to the developer-owned portions of the project, while third-party
components remain governed by their respective licenses.
