# StudentGPA AI — Deployment Guide

## 1. Overview

StudentGPA AI is a Streamlit application that can be deployed locally or through Streamlit Community Cloud.

The application source code is maintained in GitHub.

## 2. Requirements

Recommended environment:

- Python 3.11 or compatible Python version
- Git
- Internet connection
- GitHub account
- Streamlit Community Cloud account for cloud deployment

`requirements.txt`
